# Предметная область

Опорный документ — Правила вида спорта «бадминтон», приказ Минспорта России
от 12.07.2021 № 546 (ред. от 06.11.2024). Отступления от правил помечены
**[отступление]** и записаны в [decisions.md](decisions.md).

## Термины

| Термин | В коде | Значение |
|---|---|---|
| Событие | `Event` | Турнир: один зал, обычно один день. Принадлежит одному организатору. |
| Категория | `Category` | Самостоятельное соревнование внутри события. Обозначается кодом: разряд + уровень (MSB, WDE, XDD). |
| Разряд | `Discipline` | MS, WS, MD, WD, XD, OS, OD — см. ниже. |
| Уровень | `Level` | Необязательная метка силы категории: A, B, B+, B+C, 3… |
| Игрок | `Player` | Человек из общего справочника. |
| Участник | `Entry` | Тот, кто играет в категории: один игрок или пара. Хранит снимок рейтинга. |
| Этап | `Stage` | Групповой этап или плей-офф. |
| Группа | `Group` | Круговая группа внутри группового этапа (A, B, …). |
| Плей-офф | `Bracket` | Этап на выбывание. |
| Матч | `Match` | Встреча двух участников. |
| Партия | `Game` | Часть матча. В разговоре иногда «сет», в интерфейсе — «партия». |
| Корт | `Court` | Площадка, номера 1..N. |
| Очередь | `Queue` | Упорядоченный список матчей, ожидающих корта. Общая на событие. |
| Неявка | `Walkover` | Участник не вышел на матч. В таблице «н/я». |
| Отказ | `Retirement` | Участник прекратил матч по ходу. В протоколе «отказ» (Ret). |
| Снятие | `Withdrawal` | Участник выбыл из категории до конца этапа. |

## Роли

- **Суперюзер** — полный доступ. Создаётся только консольной командой на сервере.
  Суперюзеров может быть несколько.
- **Организатор** — заводится суперюзером. Создаёт события и управляет только своими.
  Соорганизаторов и судей нет: событие ведёт его владелец (с любого числа своих устройств).
- **Гость** — без входа, видит опубликованные события. В будущем — регистрация на события.

## Игроки

Общий справочник между событиями.

| Поле | Обязательное | Кто видит |
|---|---|---|
| Фамилия, имя | да | все |
| Пол | да | все (нужен для проверки разряда) |
| Клуб / город | нет | все |
| Рейтинг | нет | все |
| Год рождения | нет | только организатор |
| Контакт | нет | только организатор |
| Внешний ID | нет | только организатор (под будущую интеграцию со всероссийской базой) |

- Рейтинг — целое число, обычно 100–1000, больше = сильнее. Ведётся во внешней системе;
  пока вводится вручную, позже — по API.
- При добавлении в событие в заявке фиксируются рейтинг и клуб/город (снимок на момент
  события). Имя всегда берётся из справочника. Рейтинг пары = сумма.
- Создать игрока может любой организатор; править — автор записи и суперюзер.
- Игроков можно заводить без интернета, поэтому возможны дубли — их объединяет суперюзер
  или автор обеих записей.

## Событие

- Настройки события: число кортов, формат матча по умолчанию.
- Два независимых признака:
  - видимость: черновик (видит только владелец) / опубликовано (видят все);
  - ход: настройка → идёт → завершено.

  Можно опубликовать список участников до старта или провести турнир без публикации.
- Завершённое событие только читается. Чтобы исправить итоги, владелец возвращает его
  в работу, правит и завершает снова.
- Удалить событие владелец может, пока в нём нет ни одного сыгранного матча;
  после — только суперюзер. Владелец может снять событие с публикации.
- Игрок может участвовать в нескольких категориях одного события.

### Изменение состава по ходу

- **Опоздавший участник.** Пока ни один матч группы не вызван — расписание пересобирается.
  После — матчи новичка со всеми дописываются в конец очереди.
- **Замена партнёра в паре** — в любой момент. Результаты остаются за парой,
  у каждого матча хранится, кто реально играл.
- **Удаление участника** — только если у него нет сыгранных матчей; иначе — снятие.

## Категории и разряды

| Разряд | Состав | Пол |
|---|---|---|
| MS | одиночка | М |
| WS | одиночка | Ж |
| MD | пара | М + М |
| WD | пара | Ж + Ж |
| XD | пара | М + Ж |
| OS | одиночка | любой |
| OD | пара | любой |

- Код категории = разряд + уровень. Уровень необязателен и задаётся свободной меткой
  («B+» = B и сильнее, «B+C» = объединённая). Название формируется из кода, его можно изменить.
- Состав участника проверяется по разряду автоматически.
- У категории может быть диапазон рейтинга; выход за него — только предупреждение.

## Формат матча

Задаётся на этап категории, по умолчанию берётся из настроек события.

- Партия до 21: разница 2 очка, предел 30 (при 29:29 — до 30).
- Партия до 15: разница 2 очка, предел 21 (при 20:20 — до 21).
- Матч: 1 партия или до 2 побед (из 3 партий).
- Решающая партия может быть короче: до 15 при остальных до 21.

Других вариантов нет.

## Групповой этап

### Распределение по группам

- Есть рейтинг — змейкой по рейтингу; нет — случайно. Затем организатор правит вручную.
- Участники без рейтинга при змейке считаются слабейшими и распределяются случайно в хвосте.
- При равном рейтинге порядок определяет жребий.
- Рейтинг пары — сумма; если рейтинга нет хотя бы у одного игрока, рейтинг пары неизвестен.

### Расписание

- Круговая система: каждый с каждым. Порядок матчей — по турам; он же начальный порядок
  очереди. Внутри тура матчи не переставляются.
- Участники упорядочены по посеву так, что первый и второй встречаются в последнем туре
  (для четырёх: 1–4 и 2–3, затем 1–3 и 2–4, затем 1–2 и 3–4 — как рекомендует BWF).
- При нечётном числе участников каждый тур кто-то отдыхает.

### Места в группе

По п. 2.12.1.6.3 правил:

1. Число побед.
2. Равны двое — выше победитель их личной встречи.
3. Равны трое и больше — разница партий по всем матчам группы.
   Если после этого равны двое — личная встреча.
4. Затем разница очков по всем матчам группы. Если после этого равны двое — личная встреча.
5. Затем жребий: места расставляет организатор вручную.

Уточнения для живого турнира:

- Пока группа не доиграна, места предварительные. Несыгранная личная встреча пропускается:
  дальше разница партий, затем очков.
- Если равенство не разрешилось, участники делят место («3–4»), строки помечены.
- Жребий доступен, только когда все матчи группы сыграны, и действует только на тот же набор
  равных: если после правки результата набор изменился, нужен новый жребий.
- Снявшийся ранжируется по результатам наравне со всеми, с пометкой «снят».

### Технические результаты

- **Неявка** (п. 2.9.2): сопернику засчитывается сухая победа — 2:0 (или 1:0) по партиям,
  21:0 (или 15:0) в каждой. Неявившийся продолжает турнир. Помета «н/я».
- **Отказ по ходу матча**: в протоколе — фактический счёт и помета «отказ», победа сопернику.
  В таблице мест матч учитывается как сухая победа соперника.
- **Снятие** **[отступление]**: сыгранные матчи сохраняются, несыгранные засчитываются
  соперникам как неявка. По п. 2.12.1.6.4 правил все результаты снявшегося аннулируются.

## Ввод и правка результатов

- Вводится счёт каждой партии. Победитель определяется автоматически.
- Счёт проверяется по формату; некорректный подсвечивается, но может быть сохранён
  с подтверждением.
- Результат можно исправить. История правок в интерфейсе не показывается.
- Продолжительность матча = от вызова на корт до ввода результата.
  Время берётся с устройства организатора.
- После любого ввода или правки места пересчитываются сразу.

## Корты и очередь

- Число кортов задаётся в событии. Корт можно временно выключить.
- Очередь общая на событие (на будущее — для всех категорий).
- Освободился корт → система предлагает первый матч очереди, в котором никто из игроков
  сейчас не играет (в любой категории). Организатор подтверждает, может выбрать другой матч
  или переставить очередь.
- Минимального отдыха нет. У каждого игрока видно, сколько он отдыхает
  (время с конца его последнего матча).
- Время вызова и результата сохраняется у каждого матча: для статистики, будущего прогноза
  времени и планирования турниров.

## Плей-офф (после MVP)

- Из каждой группы выходят двое.
- Сетка: крест (1A–2B, 1B–2A, …), участники одной группы разводятся по разным половинам.
  Свободные места до степени двойки — проход без игры, достаются победителям групп.
  До первого матча сетку можно поправить вручную.
- Розыгрыш мест настраивается на этап: два третьих места, матч за 3-е место
  или розыгрыш всех мест.
- Правка результата группы после построения сетки: пока в сетке не начат ни один матч —
  сетка пересобирается (с предупреждением); после — сетка не меняется, выводится предупреждение.
