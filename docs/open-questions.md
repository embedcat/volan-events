# Открытые вопросы

## Предметная область

1. **Всероссийская база игроков**: какая именно, есть ли у неё API и что оттуда можно брать
   (рейтинг, ID, клуб). Не блокирует MVP.
2. **Правила**: текст взят с legalacts.ru; перед тем как ссылаться на правила
   в регламентах, сверить с официальным источником.

## Принято по умолчанию при составлении команд — подтвердить

3. **Явный старт**: матчи можно вызывать только после «Начать турнир» (`event.start`).
4. **Завершение** возможно, когда ни один матч не на корте; несыгранные матчи остаются
   несыгранными.
5. **Выключить корт** можно, только если он свободен — матч сначала переносится на другой корт.
6. **Отмена вызова** и **стирание ошибочного результата** возвращают матч в начало очереди.
7. **Результат можно ввести матчу из очереди** без вызова на корт (неявка, матч сыгран
   вне системы) — продолжительность тогда не считается.
8. **Фактический состав пары** фиксируется в матче при вводе результата.

## Архитектура

9. **Сборка и выкладка**: один контейнер (API + SPA) за nginx; когда и как выкладывать
   (вручную, GitHub Actions).
10. **Резервное копирование SQLite** на VPS: как часто и куда.
