# Открытые вопросы

## Предметная область

1. **Всероссийская база игроков**: какая именно, есть ли у неё API и что оттуда можно брать
   (рейтинг, ID, клуб). Не блокирует MVP.
2. **Статус и видимость события**: предлагается два независимых признака —
   видимость (черновик / опубликовано) и ход (настройка / идёт / завершено),
   чтобы можно было опубликовать список участников до старта. Подтвердить.
3. **Участники без рейтинга при змейке** — считать слабейшими и распределять случайно
   в хвосте. Подтвердить.
4. **Правила**: текст взят с legalacts.ru; перед тем как ссылаться на правила
   в регламентах, сверить с официальным источником.

## Архитектура (обсудить на этапе модели данных)

5. **Хранение события на сервере**: журнал команд + снимок состояния
   или нормализованные таблицы.
6. **Детерминированность команд**: зерно жеребьёвки в команде, ID сущностей генерирует
   клиент (UUIDv7).
7. **Аутентификация**: argon2id, серверные сессии в cookie; срок жизни сессии
   (предложение — 30 дней).
8. **Сборка и выкладка**: один контейнер (API + SPA) за nginx; когда и как выкладывать
   (вручную, GitHub Actions).
9. **Резервное копирование SQLite** на VPS: как часто и куда.
