# Экраны

## Принципы

- Чистый технический интерфейс: без картинок и логотипов, плотные таблицы, системный шрифт.
- Светлая и тёмная тема по настройке системы, переключается вручную.
- Телефон, планшет, ноутбук. На широких экранах разделы события — вкладки сверху,
  на телефоне — панель внизу.
- Имена всегда «Фамилия Имя», пара — «Иванов Иван / Сидоров Сергей».
- **Подтверждений нет.** Действие выполняется сразу, на несколько секунд появляется плашка
  «… [Отменить]». Отмена выполняет обратную команду. Единственное исключение — удаление
  события: нужно ввести его название.
- Организатор и гость смотрят одни и те же страницы; владелец видит кнопки управления,
  пульт и настройки.
- Время на экране обновляется раз в минуту: «на корте 14 мин», «отдых 8 мин».

## Карта экранов и адреса

| Адрес | Экран | Кто |
|---|---|---|
| `/` | Опубликованные события: идут, предстоят, прошли | все |
| `/login` | Вход | — |
| `/my` | Мои события, «Создать событие» | организатор |
| `/e/:id/courts` | Гостю — корты и очередь; владельцу — **пульт** | все |
| `/e/:id/table` | Таблица группы | все |
| `/e/:id/matches` | Все матчи | все |
| `/e/:id/entries` | Участники | все |
| `/e/:id/settings` | Настройки и готовность к старту | владелец |
| `/e/:id/print` | Итоговый протокол для печати | все |
| `/players` | Справочник игроков | организатор |
| `/sync` | Синхронизация и конфликты | организатор |
| `/account` | Мои устройства, пароль, тема | организатор |
| `/admin/users` | Пользователи | суперюзер |

`/e/:id` открывает «Корты», пока турнир идёт, и «Таблицу» — когда он завершён или ещё
не начат.

## Шапка и индикатор связи

```
┌──────────────────────────────────────────────────────────────────────────┐
│ Осенний турнир клуба · 26.10 · идёт          ● онлайн            Иванов ▾│
│ [Пульт] [Таблица] [Матчи] [Участники] [Настройки]                        │
└──────────────────────────────────────────────────────────────────────────┘
```

Состояния индикатора (у организатора):

| Вид | Значение |
|---|---|
| `● онлайн` | всё отправлено |
| `○ нет связи · 3 ждут отправки` | работа без сети |
| `◐ отправка…` | идёт синхронизация |
| `▲ конфликты: 2` | есть отклонённые команды → `/sync` |

У гостя: `обновлено в 14:32`.

На телефоне вкладки уходят в панель внизу:

```
├──────────────────────────────────────┤
│ Пульт  Таблица  Матчи  Участн.  Ещё  │
└──────────────────────────────────────┘
```

## Пульт (владелец, турнир идёт)

### Ноутбук, планшет

```
┌ Корт 1 ─────────────────┐ ┌ Корт 2 ─────────────────┐ ┌ Корт 3 ─────────────────┐
│ №7 · тур 2 · 14 мин     │ │ свободен                │ │ №8 · тур 2 · 3 мин      │
│ Иванов Иван             │ │ дальше: №9              │ │ Орлов Олег              │
│ Петров Пётр             │ │ Сидоров Сергей          │ │ Белов Борис             │
│                         │ │ Козлов Кирилл           │ │                         │
│ [Результат]          ⋯  │ │ [Вызвать]  другой матч… │ │ [Результат]          ⋯  │
└─────────────────────────┘ └─────────────────────────┘ └─────────────────────────┘
┌ Корт 4 ─────────────────┐
│ выключен     [Включить] │
└─────────────────────────┘

ОЧЕРЕДЬ · 14 матчей
 №   тур  участники                          состояние                         
 9   2    Сидоров Сергей – Козлов Кирилл     отдых 8 мин / 21 мин   [На корт ▾] ⋯
 10  3    Орлов Олег – Иванов Иван           Орлов на корте 3, Иванов на корте 1   ⋯
 11  3    Белов Борис – Петров Пётр          Белов на корте 3, Петров на корте 1   ⋯
 12  3    Козлов Кирилл – Сидоров Сергей     отдых 21 мин / 8 мин   [На корт ▾] ⋯
 …
```

**Карточка корта**

| Состояние | Что видно | Действия |
|---|---|---|
| занят | №, тур, участники, сколько идёт матч | `Результат`; `⋯` → перенести на другой корт, отменить вызов |
| свободен | подсказка — первый матч очереди со свободными игроками | `Вызвать`; «другой матч…» — список доступных матчей |
| свободен, подсказки нет | «все ожидающие игроки на кортах» | — |
| выключен | — | `Включить` |

`⋯` у свободного корта — «Выключить».

**Строка очереди**

- Отдых каждого участника (для пары — по последнему сыгравшему из двух) или «на корте N».
- `На корт ▾` — список свободных кортов; недоступно, если кто-то из игроков на корте.
- `⋯` — переместить (в начало, в конец, на позицию), ввести результат без вызова (неявка).
- На ноутбуке строки можно перетаскивать для перестановки.

## Ввод результата

Окно поверх пульта; на телефоне — на весь экран.

```
┌ Матч №7 · Корт 1 · 14 мин · до 2 побед, партия до 21 ──────────────┐
│                                                                    │
│              Иванов Иван / Сидоров Сергей   Петров Пётр / Козлов К…│
│  Партия 1    [ 21 ]                         [ 15 ]                 │
│  Партия 2    [ 18 ]                         [ 21 ]                 │
│  Партия 3    [ 21 ]                         [ 19 ]   ← до 15? нет  │
│                                                                    │
│  Победитель: Иванов Иван / Сидоров Сергей · 2:1                    │
│                                                                    │
│  [Неявка…] [Отказ…]                          [Отмена] [Сохранить]  │
└────────────────────────────────────────────────────────────────────┘
```

- Числовая клавиатура, переход к следующему полю автоматически.
- **Подстановка**: ввёл одно число — второе подставляется, только если введённое число
  может быть лишь у проигравшего: до 21 — 0–19 → 21, 20 → 22; до 15 — 0–13 → 15, 14 → 16.
  Числа от 21 (от 15) неоднозначны: 23 бывает и 23:21, и 23:25 — тогда ничего
  не подставляется. Подставленное можно переписать.
- Строки партий — по формату этапа; третья появляется при счёте 1:1.
- Некорректный счёт подсвечивается с объяснением («при 20:20 игра идёт до разницы в 2»);
  кнопка меняется на «Сохранить как есть» (`nonStandard`).
- **Неявка…** — выбрать, кто не явился. **Отказ…** — выбрать, кто отказался;
  поля счёта остаются для фактического счёта до отказа.
- После сохранения — плашка «Результат №7 сохранён [Отменить]».

## Таблица группы

Шахматка на всех устройствах; на телефоне — горизонтальная прокрутка, колонка имён
закреплена.

```
 Группа A · MSB                                       обновлено в 14:32
┌───────────────────┬────────┬────────┬────────┬────────┬─────┬───────┬──────┬───────┐
│                   │ Ивано… │ Сидор… │ Петро… │ Козло… │ П-П │ Парт. │ Очки │ Место │
├───────────────────┼────────┼────────┼────────┼────────┼─────┼───────┼──────┼───────┤
│ Иванов Иван       │ ██████ │ 21:15  │ н/я    │        │ 2-0 │ +2    │ +27  │ 1     │
│ Сидоров Сергей    │ 15:21  │ ██████ │ 2:1    │ 21:18  │ 2-1 │ +1    │ +4   │ 2     │
│ Петров Пётр       │ н/я    │ 1:2    │ ██████ │        │ 0-2 │ −3    │ −24  │ 4     │
│ Козлов Кирилл     │        │ 18:21  │        │ ██████ │ 0-1 │ −1    │ −3   │ 3     │
└───────────────────┴────────┴────────┴────────┴────────┴─────┴───────┴──────┴───────┘
```

- В ячейке: счёт одной партии или счёт по партиям для матча до 2 побед;
  нажатие — подробности матча.
- Пометки: `н/я`, `отк.`, `снят` у участника.
- Если равенство решается жребием — строки выделены, у владельца кнопка «Жребий»:
  расставить вручную.
- Пока сыграно не всё, места предварительные.

## Матчи

```
 Все · Ожидают · На кортах · Сыграны

 Тур 1
 №1  Иванов Иван – Сидоров Сергей    21:15          корт 1 · 12:05 · 16 мин   [Изменить]
 №2  Петров Пётр – Козлов Кирилл     н/я Петров                               [Изменить]
 Тур 2
 №7  Иванов Иван – Петров Пётр       на корте 1 · 14 мин
 №9  Сидоров Сергей – Козлов Кирилл  в очереди, 1-й
```

Владелец: `Изменить` — то же окно ввода результата; `⋯` — стереть результат.

## Участники

- Список: №, участник, клуб (снимок), рейтинг (снимок), статус.
- Владелец: «Добавить» — поиск по справочнику по мере ввода, для пары — два игрока;
  «Новый игрок» прямо отсюда. Рейтинг вне диапазона категории — предупреждение.
- `⋯` у участника: заменить партнёра, снять, вернуть, удалить (если нет сыгранных матчей).

## Настройки (владелец)

```
 ГОТОВНОСТЬ К СТАРТУ
  ✓ Событие: название, дата, корты
  ✓ Категория MSB
  ✗ Участников: 1 — нужно минимум 2
  ✗ Расписание не составлено
                                                 [Начать турнир] (недоступна)

 СОБЫТИЕ       название · дата · место · видимость: черновик / опубликовано
 КОРТЫ         количество · формат матча по умолчанию
 КАТЕГОРИЯ     разряд · уровень · название · диапазон рейтинга · формат матча
 РАСПИСАНИЕ    [Составить] / [Пересобрать] — пока ни один матч не вызван
 ТУРНИР        [Начать турнир] · [Завершить] · [Вернуть в работу]
 ОПАСНО        [Удалить событие] — ввести название для подтверждения
```

## Страница гостя

Те же вкладки без «Настроек»: Корты · Таблица · Матчи · Участники.
«Корты» у гостя — карточки кортов без кнопок плюс «Следующие» (первые 5 матчей очереди).
Эта же вкладка подходит для ТВ в зале.

## Синхронизация и конфликты (`/sync`)

```
 Состояние: онлайн · последняя синхронизация 14:32 · ждут отправки: 0

 КОНФЛИКТЫ
 ▲ Матч №7: результат
   у вас (телефон, 14:10):  21:15
   на сервере (ноутбук):    21:17
   [Применить моё]  [Отбросить]

 ▲ Вызов №12 на корт 2: корт уже занят матчом №11
   [Отбросить]
```

## Справочник игроков

- Поиск по фамилии, таблица: фамилия, имя, пол, клуб, рейтинг, автор.
- Создать, править (автор и суперюзер), объединить (суперюзер или автор обеих записей).

## Пользователи (суперюзер)

- Список: логин, имя, роль, активен, последнее появление.
- Создать организатора, заблокировать, сбросить пароль, отозвать все сессии.

## Итоговый протокол (печать)

Название, дата, место, категория, формат; шахматка; места; все матчи по турам со счётом,
кортом, временем и продолжительностью; пометки н/я, отказ, снят; число кортов,
время начала и окончания турнира.
