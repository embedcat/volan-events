# volan-events — документация

Сервис для проведения бадминтонных турниров: категории, группы, корты и очередь,
ввод счёта, живая таблица мест, работа без интернета с последующей выгрузкой.

Состояние на 2026-10-20: планирование завершено в первом приближении, кода нет.

| Документ | Что внутри |
|---|---|
| [domain.md](domain.md) | Термины, роли, правила турнира: категории, счёт, места, неявки, корты |
| [architecture.md](architecture.md) | Устройство системы: команды, синхронизация, оффлайн, стек, развёртывание |
| [data-model.md](data-model.md) | Таблицы сервера, состояние события, хранилище браузера, версии |
| [commands.md](commands.md) | Конверт команды, обработка, конфликты, API, каталог команд MVP, отмена |
| [screens.md](screens.md) | Принципы интерфейса, карта экранов и адресов, наброски главных экранов |
| [mvp.md](mvp.md) | Объём первого этапа, критерии готовности, дальнейшие этапы |
| [decisions.md](decisions.md) | Журнал решений: что решили, почему, что отвергли |
| [open-questions.md](open-questions.md) | Что ещё не решено |

Правило: любое техническое решение и любой неясный момент предметной области
сначала обсуждается, затем фиксируется в `decisions.md` и в профильном документе.
